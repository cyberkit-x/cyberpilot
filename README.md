# CyberPilot

CyberPilot is an open-source agentic security operator for authorized vulnerability hunting.

The project is designed as a CLI/TUI product for expert red teams. A user provides an objective and scope; CyberPilot selects and combines community-maintained attack skills, executes work through a controlled runner, and preserves reproducible evidence.

## Project direction

- Natural-language task creation
- Long-running, resumable hunt sessions
- Agentic planning: observe, reason, act, verify, and re-plan
- Community-contributed attack skills
- Safe execution through Docker or Podman runners
- CLI automation with `cyberpilot exec`
- TUI visibility across concurrent sessions

CyberPilot is intended for authorized testing only.

## Status

Early design and bootstrap stage.
